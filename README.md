# Gym Log

A tiny, single-file workout tracker. Open `index.html` in any browser — no build, no server.

- **Log**: pick an exercise, enter weight × reps, tap *Add set*. Known exercises autocomplete and prefill your last weight/reps.
- **History**: every session by day. Tap ✕ to delete a set.
- **Progress**: per-exercise estimated 1RM chart (Epley), heaviest weight, session count. New PRs are flagged in the log.
- **Settings**: lb/kg, export/import your data as JSON.

Data lives in your browser's localStorage, so export now and then as a backup.
